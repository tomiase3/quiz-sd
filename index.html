☁️ PENYIMPANAN CLOUD

Hubungkan Supabase

Masukkan URL proyek dan anon / publishable key dari pengaturan proyek Supabase. Kredensial tersimpan di browser ini.
🚀 PANDUAN SINGKAT

Aktifkan penyimpanan cloud

  1. Buat proyek gratis di supabase.com.
  2. Buka SQL Editor, lalu jalankan isi file supabase.sql yang tersedia di folder aplikasi.
  3. Salin Project URL dan anon/publishable key dari Project Settings → API.
  4. Tempelkan keduanya pada formulir pengaturan Supabase. Jangan pernah masukkan service_role key.

Tanpa konfigurasi, aplikasi tetap berjalan dengan penyimpanan lokal di browser ini.
